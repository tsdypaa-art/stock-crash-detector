# 📈 LINE通知機能付き・リアルタイム株価急落監視システム

このシステムは、指定した株式銘柄を1分ごとにリアルタイム監視し、前日比-2%以下の急落（暴落）を検知した瞬間にLINEへアラートを通知するサーバーレスシステムです。

## 🛠️ 使用テクノロジー
- **Language:** Python 3.x (yfinance)
- **AWS:** Lambda, API Gateway, DynamoDB, EventBridge
- **API:** LINE Messaging API (Push/Reply)
- **CI/CD:** GitHub Actions (自動デプロイ)

## 📱 主な機能
1. **1分間隔のリアルタイム監視:** 平日の市場稼働時間中、1分ごとに株価をチェック。
2. **LINEからの操作:** LINEでメッセージを送るだけで簡単に管理。
   - `追加 [銘柄コード] [会社名]` : 監視対象の追加
   - `削除 [銘柄コード]` : 監視対象の削除
   - `一覧` : 現在監視している銘柄のリスト表示
